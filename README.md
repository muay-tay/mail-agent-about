# mail-agent — öffentliche Seite

Diese Seite existiert aus einem einzigen Grund: Google verlangt für die
Veröffentlichung einer OAuth-Anwendung öffentlich erreichbare Links zu
Startseite, Datenschutzerklärung und Nutzungsbedingungen. Ohne sie bleibt
die Schaltfläche „Publish app" deaktiviert, und Zugriffstoken laufen alle
sieben Tage ab.

Inhalt: `index.html`, veröffentlicht über GitHub Pages.

Die Anwendung selbst liegt in einem privaten Repository.
